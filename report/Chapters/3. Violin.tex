\section*{Exercise 7.12: Analyzing a Note Played by a Violin}

\subsection*{Part 1: MATLAB Implementation (\texttt{dft\_unknown\_note.m})}

Below is the MATLAB script \texttt{dft\_unknown\_note.m} written to read the audio recording \texttt{unknown\_note.wav}, calculate its Discrete Fourier Transform (DFT), and plot the magnitude spectrum for the bottom half of the frequency range (from DC up to the Nyquist frequency):

\begin{lstlisting}[caption={MATLAB script \texttt{dft\_unknown\_note.m} for spectral analysis of \texttt{unknown\_note.wav}}, label={lst:dft_unknown_note}]
% 1. Read the audio file unknown_note.wav and retrieve sampling frequency
[f, nu_s] = audioread('unknown_note.wav');

% 2. Extract the first channel if stereo
f = f(:, 1);
N = length(f);

% 3. Compute the Discrete Fourier Transform (DFT)
F = fft(f);
magF = abs(F);

% 4. Create the frequency vector (DC to Nyquist)
halfN = floor(N / 2) + 1;
mag_half = magF(1:halfN);
nu_half = (0:halfN - 1)' * (nu_s / N);

% 5. Plot the bottom half of the spectrum as a function of nu
figure;
plot(nu_half, mag_half);
xlabel('\nu (Hz)');
ylabel('|F(\nu)|');
title('Bottom half of the spectrum (DC to Nyquist)');
grid on;

% 6. Automatically extract the fundamental frequency
[max_val, max_idx] = max(mag_half);
base_freq = nu_half(max_idx);
fprintf('Fundamental (base) frequency: %.2f Hz\n', base_freq);
\end{lstlisting}

    \item \textbf{Noise Level:} The spectral energy between the harmonic peaks is virtually zero, confirming a clean recording with minimal background noise.

\subsubsection*{2. Base Frequency and Musical Note Determination}
From the peak analysis of the spectrum:
\begin{equation}
    \text{Base Frequency } (\nu_0) \approx 466.2\text{ Hz}
\end{equation}

Comparing $\nu_0 = 466.2\text{ Hz}$ against the standard musical note frequency reference table (equal temperament with $\text{A4} = 440.0\text{ Hz}$):
\begin{itemize}
    \item $\text{A4} = 440.00\text{ Hz}$
    \item $\mathbf{A\sharp4 / B\flat4 = 466.16\text{ Hz}}$
    \item $\text{B4} = 493.88\text{ Hz}$
\end{itemize}

\textbf{Conclusion:} The note being played by the violinist in \texttt{unknown\_note.wav} is \textbf{A$\sharp$4} (A-sharp in octave 4) or \textbf{B$\flat$4} (B-flat in octave 4).
