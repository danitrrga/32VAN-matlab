\section{Introduction} 
This report presents the solutions and findings for the \textbf{DFT/DFT2 Project} in Vector Analysis. The primary objective of this project is to explore the theoretical foundations and practical applications of the Discrete Fourier Transform (DFT) in 1D and 2D using MATLAB. The topics covered range from fundamental signal discretization and audio analysis (violin notes and human vocal formants) to 2D image processing (image smoothing) and physical wave optics (Fraunhofer diffraction patterns).
